# Contributing

Thanks for your interest in FairGate.

## Before submitting changes

1. Keep synthetic demonstration data clearly labelled.
2. Never commit private applicant data, credentials, API keys, or local environment files.
3. Document changes to feature definitions, sensitive attributes, fairness metrics, thresholds, and decision semantics.
4. Include tests for changes to data preparation, prediction, fairness evaluation, mitigation, and monitoring.
5. Report the dataset, split strategy, random seed, dependency versions, and evaluation metrics when sharing experiment results.

## Reproducibility status

This repository currently contains project documentation based on the presentation. The original notebook and source tree still need to be added before contributors can run the full pipeline or reproduce the reported results.
